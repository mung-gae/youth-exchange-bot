# 청춘거래소 Python 디스호스트 설치 안내

이 완성본은 Python 기반 디스호스트/Pterodactyl 환경에서 `python app.py`로 실행됩니다.

## 포함 파일

- `app.py`
- `youth_exchange.py`
- `requirements.txt`
- `.env.example`
- `README-DISHOST.md`
- `data/.gitkeep`

## 설치 순서

1. Python 3.11 이상 서버를 생성합니다.
2. GitHub Actions 아티팩트 `청춘거래소-파이썬-디스호스트`를 다운로드합니다.
3. 완성본 ZIP을 Files 메뉴에 업로드하고 압축 해제합니다.
4. `.env.example`을 참고해 `.env`를 작성합니다.
5. 라이브러리 설치 메뉴가 있다면 다음을 등록합니다.
   - `discord.py==2.4.0`
   - `python-dotenv==1.0.1`
6. 시작 명령을 `python app.py`로 지정합니다.
7. 서버를 시작합니다.

## 자동 처리

서버가 시작되면 청춘거래소는 다음 작업을 자동으로 수행합니다.

1. `data` 폴더 생성
2. SQLite 데이터베이스 연결
3. 데이터베이스 마이그레이션
4. 고정 아이템 등록
5. `/계절투자` 슬래시 명령어 자동 등록
6. Discord 봇 로그인


## 라운드 운영

`다음라운드` 실행 후에는 새 라운드가 `SETTING` 상태로 시작됩니다. 참가자의 잔액, 판매 수익, 보유 아이템은 그대로 유지되고 기존 공개 아이템도 계속 공개됩니다. 운영진은 아직 공개되지 않은 아이템을 추가 공개할 수 있으며, 이후 구매 시작, 참가자 추가 구매, 구매 종료, 매입금 설정, 매입금 공개, 외부 계절 결과 입력, 판매, 정산 순서로 진행합니다. 남은 아이템은 이벤트를 최종 종료할 때만 환급 없이 소멸하며, 다음 라운드 이동 중에는 `ROUND_ITEM_EXPIRATION` 거래를 새로 만들지 않습니다.

## 주의사항

- 실제 `.env`와 `data/youth-exchange.db`는 업로드 공유나 커밋 대상이 아닙니다.
- Node.js, npm, package.json, package-lock.json은 필요하지 않습니다.

## 실시간 거래 로그

관리자 전용 채널을 만든 뒤 다음 명령어로 거래 로그를 켤 수 있습니다.

```text
/계절투자 이벤트관리 거래로그설정
채널: #청춘거래소-관리로그
활성화: 예
```

관리자는 다음 명령어로 최근 거래, 구매 현황, 판매 현황을 관리자에게만 보이게 조회할 수 있습니다.

```text
/계절투자 조회 실시간거래
/계절투자 조회 구매현황
/계절투자 조회 판매현황
```

거래 로그에는 참가자의 구매 아이템, 수량, 잔액이 표시됩니다. 반드시 일반 유저가 볼 수 없는 관리자 전용 채널로 설정하세요.
